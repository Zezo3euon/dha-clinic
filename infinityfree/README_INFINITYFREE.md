# 🚀 دليل تشغيل نظام عيادة د. حاتم عواجة على موقع InfinityFree.com

تم تحويل النظام بالكامل ليعمل بتقنية **PHP 8 + MySQL** المتوافقة 100% مع استضافة **InfinityFree**.

---

## 📂 محتويات المجلد:
1. **`dha_clinic_mysql.sql`**: ملف قاعدة بيانات MySQL جاهز للاستيراد في phpMyAdmin.
2. **`htdocs/`**: المجلد الكامل الذي سيتم رفعه للاستضافة.
3. **`infinityfree_htdocs.zip`**: ملف مضغوط جاهز للرفع المباشر إذا أردت الرفع بنقرة واحدة عبر File Manager.

---

## 🛠️ خطوات التشغيل خطوة بخطوة:

### الخطوة 1: إنشاء قاعدة بيانات MySQL على InfinityFree
1. ادخل إلى حسابك في [InfinityFree Dashboard](https://dash.infinityfree.com/accounts).
2. افتح حساب الاستضافة الخاص بك واضغط على زر **Control Panel** (vPanel).
3. ابحث عن قسم **Databases** واضغط على **MySQL Databases**.
4. في خانة **Create New Database**، اكتب اسماً لقاعدة البيانات (مثلاً: `clinic` أو `dha`).
5. اضغط **Create Database**.
6. **هام جداً:** بعد الإنشاء، ستظهر لك بيانات الاتصال في نفس الصفحة، انسخها واحفظها:
   - **MySQL Host Name** (مثال: `sql123.infinityfree.com` — *تأكد من نسخه وليس localhost*).
   - **MySQL Database Name** (مثال: `if0_12345678_clinic`).
   - **MySQL User Name** (مثال: `if0_12345678`).
   - **MySQL Password** (كلمة مرور حسابك في vPanel).

---

### الخطوة 2: استيراد الجداول عبر phpMyAdmin
1. في نفس صفحة **MySQL Databases** في الـ vPanel، اضغط على زر **phpMyAdmin** بجانب قاعدة البيانات التي أنشأتها.
2. سيفتح لك موقع phpMyAdmin:
   - من القائمة العلوية اضغط على **Import** (استيراد).
   - اضغط **Choose File** (اختيار ملف).
   - اختر الملف الموجود على جهازك:
     `c:\DHA\infinityfree\dha_clinic_mysql.sql`
   - انزل لأسفل الصفحة واضغط **Import** أو **Go**.
3. ستظهر رسالة خضراء تفيد بنجاح استيراد كافة الجداول (المريضات، الكشوفات، السونار، الروشتات، الأدوية).

---

### الخطوة 3: تعديل بيانات الاتصال في ملف `config.php`
افتح الملف التالي في محرر النصوص على جهازك:
`c:\DHA\infinityfree\htdocs\api\config.php`

وقم بتعديل القيم بالبيانات التي نسختها في الخطوة 1:
```php
return [
    'db_host' => 'sqlXXX.infinityfree.com', // سيرفر MySQL الخاص بحسابك
    'db_name' => 'if0_XXXXXXXX_clinic',      // اسم قاعدة البيانات الكامل
    'db_user' => 'if0_XXXXXXXX',             // اسم المستخدم
    'db_pass' => 'كلمة_مرور_حسابك',          // كلمة المرور
    ...
];
```
واحفظ الملف.

---

### الخطوة 4: رفع الملفات إلى الاستضافة (File Manager)
1. في لوحة تحكم InfinityFree، اضغط على **Online File Manager** (أو افتح برنامج FileZilla إذا كنت تفضل FTP).
2. ادخل إلى مجلد **`htdocs`** الرئيسي الخاص بنطاقك.
3. إذا وجدت داخله ملفات افتراضية قديمة (مثل `index2.html` أو `default.php`) قم بحذفها.
4. ارفع كافة الملفات والمجلدات الموجودة داخل:
   `c:\DHA\infinityfree\htdocs\`
   أو قم برفع الملف المضغوط:
   `c:\DHA\infinityfree_htdocs.zip`
   ثم فك ضغطه (Extract) داخل مجلد `htdocs`.

---

### الخطوة 5: تشغيل النظام!
افتح متصفحك واكتب رابط موقعك على InfinityFree (مثال: `http://your-subdomain.infinityfreeapp.com`).

🎉 مبروك! سيعمل نظام عيادة الدكتور حاتم عواجة بالكامل:
- كافة الصفحات السبعة المستقلة (لوحة التحكم، المريضات، المواعيد، الكشوفات، الروشتات، الحاسبة، والنسخ الاحتياطية).
- تخزين صور السونار والتحاليل في قاعدة بيانات MySQL.
- التنبيهات الدوائية لحساسية البنسلين وتداخلات الحديد والكالسيوم.
- إرسال تذكيرات الواتساب بنقرة واحدة.
- وضع خصوصية شاشة الاستقبال.
