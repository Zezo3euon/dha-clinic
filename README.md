# 🏥 نظام إدارة عيادة الدكتور حاتم عواجة (نساء وتوليد وعقم)
### Dr. Hatem Awaja Clinic Management System (Obstetrics & Gynecology)

نظام ويب متكامل وحديث لإدارة عيادة الدكتور حاتم عواجة، استشاري أمراض النساء والتوليد وجراحة المناظير وعلاج العقم. تم تصميمه بواجهة عربية عصرية وسريعة الاستجابة (RTL)، مع قاعدة بيانات مؤمنة وتعمل على **Docker Desktop**.

---

## 🌟 مميزات النظام الرئيسية

### 1. 📊 لوحة التحكم والإحصائيات الحية (Dashboard)
- عدادات فورية: إجمالي المريضات، متابعات الحمل النشطة، كشوفات اليوم، والروشتات الصادرة.
- **طابور الانتظار لليوم (Live Clinic Queue):** عرض أرقام الأدوار للمريضات، مع إمكانية تحويل الحالة بضغطة زر (`محجوز` ⬅ `في الانتظار` ⬅ `جاري الكشف` ⬅ `مكتمل`).
- **زر بدء الكشف المباشر:** ينقل الطبيب مباشرة من طابور الانتظار إلى تسجيل الفحص والتشخيص.

### 2. 👩‍🍼 سجل وملفات المريضات الشامل (Patient Records)
- تسجيل البيانات الشخصية، أرقام الهواتف، هاتف الزوج، العنوان، وفصيلة الدم.
- **التاريخ التوليدي والنسائي التخصصي (Obstetric History):**
  - عدد مرات الحمل ($G$).
  - عدد مرات الولادة ($P$).
  - حالات الإجهاض ($A$).
  - الأطفال الأحياء ($L$).
  - عدد الولادات القيصرية ($CS$) والطبيعية.
- **متابعة الحمل الحالي:** تسجيل تاريخ آخر دورة ($LMP$) مع الحساب التلقائي للموعد المتوقع للولادة ($EDD$) وعمر الحمل.
- **الملف الطبي الشامل للمريضة:** نافذة تعرض السجل الزمني الكامل للكشوفات السابقة، قياسات الضغط والوزن والسونار، والروشتات المصروفة لها سابقاً.

### 3. 🗓️ نظام الحجوزات وقائمة الانتظار (Appointments & Scheduling)
- حجز مواعيد دقيقة بالتاريخ والوقت ورقم الدور التلقائي.
- تصنيف نوع الكشف (كشف جديد، استشارة ومراجعة، متابعة حمل دورية، فحص سونار تفصيلي، تركيب لولب).
- تسجيل قيمة الكشف وحالة السداد المالي (مدفوع / غير مدفوع).

### 4. 🩺 تسجيل الكشوفات والتشخيصات بالتوقيت والتواريخ (Clinical Visits & Diagnosis)
- تسجيل التوقيت الدقيق بالثواني والتاريخ الحي لكل كشف.
- **العلامات الحيوية وسونار الحمل:**
  - ضغط الدم، الوزن الحالي، درجة الحرارة.
  - عمر الحمل بالأسابيع ($GA$).
  - نبض الجنين ($FHR$) ومعدل ضربات القلب.
  - نتائج فحص السونار والأشعة التلفزيونية ($Ultrasound\ Findings$) مثل وضعية الجنين وسلامة المشيمة والسائل الأمنيوسي.
- **التشخيص الطبي الدقيق ($Diagnosis$)** والملاحظات الإكلينيكية وموعد المتابعة القادمة.
- إمكانية الانتقال الفوري لطباعة الروشتة فور حفظ الكشف.

### 5. 💊 الروشتة الطبية الإلكترونية والطباعة الفاخرة (Prescriptions & Printing)
- تصميم روشتة فخم وأنيق يحمل اسم وبيانات د. حاتم عواجة وترويسة رسمية باللغتين العربية والإنجليزية.
- **بنك أدوية النساء والتوليد السريع (1-Click Presets):** أزرار جاهزة لأهم أدوية التخصص (حمض الفوليك، دوفاستون، برونتوجست، حديد، كالسيوم، نافيدوكسين، كلكسان، أوجمنتين...) لسرعة إدراجها مع الجرعات.
- إمكانية إضافة أي دواء مخصص، الجرعة، التكرار، والمدة.
- حقل خاص بالإرشادات والتوجيهات الطبية للمريضة.
- **طباعة فورية مصممة لمقاسات A5 أو A4** عبر تنسيقات CSS احترافية تخفي واجهة التطبيق وتطبع فقط ورقة الروشتة الطبية بوضوح عالي، مع خيار الحفظ كـ PDF.

### 6. 🧮 حاسبة الحمل وتطور الجنين التخصصية (Obstetric Calculator)
- حساب دقيق وفق قاعدة نايجل العالمية ($Naegele's\ Rule$).
- استخراج:
  - الموعد المتوقع للولادة ($EDD$).
  - عمر الحمل الدقيق بالأسابيع والأيام.
  - تاريخ الإخصاب التقديري.
  - الثلث الحالي للحمل ($Trimester$).
  - الفحوصات والتحاليل الطبية الموصى بها إكلينيكياً في هذا الأسبوع تحديداً.

## 🐳 تشغيل النظام عبر Docker Desktop

النظام مهيأ بالكامل للعمل داخل حاويات Docker مع قاعدة بيانات **PostgreSQL 16** وحفظ دائم للبيانات:

### الخيار 1: تشغيل كل شيء في Docker (قاعدة البيانات + التطبيق)
تأكد من فتح برنامج **Docker Desktop** ثم نفذ في الطرفية:
```bash
docker compose up -d
```
افتح المتصفح على:
👉 **`http://localhost:5050`**

### الخيار 2: تشغيل قاعدة البيانات في Docker والتطبيق محلياً
1. تشغيل حاوية قاعدة البيانات فقط:
```bash
docker compose up -d dha-db
```
2. تشغيل التطبيق في جهازك:
```bash
npm start
```
أو وضع التطوير التلقائي:
```bash
npm run dev
```

## 🎨 التقنيات المستخدمة
- **الواجهة الأمامية (Frontend):** HTML5 دلالي، CSS3 حديث مع تأثيرات زجاجية (Glassmorphism)، تصميم متوافق 100% مع الاتجاه العربي RTL، خطوط Cairo الطبية من Google Fonts.
- **الواجهة الخلفية (Backend):** Node.js & Express RESTful API.
- **قاعدة البيانات (Database):** PostgreSQL 16 مدعومة بحاوية Docker Desktop مع فوليوم دائم لحماية بيانات المرضى.
- **الطباعة (Print Engine):** Media Query `@media print` عالي الدقة بدون أي عناصر تشويش.
